# ProtrenerovKids.ru — тексты SMS-сообщений

Все шаблоны — с учётом обычных ограничений SMS-провайдеров (латиница считается
дешевле, но у нас кириллица неизбежна; кириллическое сообщение режется по 70
символов на сегмент вместо 160 — старалась укладываться в 1 сегмент там, где
реально важна скорость и стоимость, но не в ущерб понятности).

Плейсхолдеры — `{в фигурных скобках}`, разработчик подставляет реальные значения.

---

## 1. Коды подтверждения (OTP)

### 1.1. Вход в кабинет тренера / менеджера (SMS-код)
```
ProtrenerovKids.ru: код для входа — {code}. Никому не сообщайте его.
```
*(56 символов — укладывается в 1 сегмент)*

### 1.2. Подтверждение отзыва
```
ProtrenerovKids.ru: код для публикации отзыва — {code}. Действует 5 минут.
```

### 1.3. Подтверждение записи на тренировку
```
ProtrenerovKids.ru: код для подтверждения записи — {code}.
```

## 2. Уведомления тренеру

### 2.1. Новая заявка от ученика (режим «форма»)
```
ProtrenerovKids.ru: новая заявка от {clientName}, тел. {clientPhone}. Посмотреть — в кабинете тренера: {link}
```

### 2.2. Приглашение разместить анкету (после звонка менеджера)
```
{managerName} из ProtrenerovKids.ru: спасибо за разговор! Ссылка для подтверждения анкеты — {claimUrl}. Ссылка действует 7 дней.
```
*Важно: этому SMS должен предшествовать звонок, где менеджер уже представился —
само SMS не заменяет обязанность назвать себя и источник контакта (152-ФЗ ст.18 ч.3),
см. `API.md`, раздел про `/api/referrals`.*

### 2.3. Анкета прошла проверку документов
```
ProtrenerovKids.ru: ваши документы проверены, на анкете появился значок «Документы проверены».
```

### 2.4. Новый отзыв получен
```
ProtrenerovKids.ru: у вас новый отзыв ({rating} из 5). Посмотреть и ответить — {link}
```

### 2.5. Бонус за 10 отзывов (геймификация)
```
ProtrenerovKids.ru: поздравляем — 10 отзывов собрано! Начислили месяц Премиума бесплатно.
```

### 2.6. Напоминание об истечении премиум-подписки
```
ProtrenerovKids.ru: премиум-подписка закончится {date}. Продлить — в кабинете тренера.
```

## Общие правила для разработчика

1. **Каждое SMS начинается с «ProtrenerovKids.ru:»** — по 152-ФЗ и просто из вежливости
   получатель должен сразу понимать, кто пишет, до того как откроет сообщение.
2. **Коды подтверждения — 6 цифр**, живут 5 минут (см. `src/routes/public/reviews.js`,
   `TTL = 5 * 60 * 1000`). Такой же TTL стоит держать и для остальных OTP-сценариев.
3. **Ссылки — короткие**, лучше через собственный редирект-домен (`p-tr.ru/...` или
   аналог), а не кириллический `.рф` — кириллица в SMS-ссылке на некоторых
   телефонах не кликается как ссылка.
4. **Не смешивать код и рекламный текст в одном SMS** — операторы могут закинуть
   такое сообщение в спам, а код подтверждения должен доходить гарантированно.
5. Разделы 2.2 и 3.2 напрямую связаны с обязанностью представиться при холодном
   контакте (см. `API.md` → `POST /api/referrals`) — юридическая логика уже
   учтена в самом коде, тексты выше её просто поддерживают.
