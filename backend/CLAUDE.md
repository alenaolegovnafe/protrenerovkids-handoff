Этот файл — для любой будущей сессии Claude (в Claude Code или в чате),
которая продолжит работу над этим проектом. Здесь собраны решения,
которые не всегда видны прямо из кода, но важны для дальнейшей работы.

## Что это за проект

Маркетплейс тренеров по фигурному катанию и хоккею для детей, Екатеринбург.

## Ключевые бизнес-решения

**Монетизация:** не полный премиум-пакет сразу, а один платный модуль —
«Прямой контакт» (телефон/Telegram/MAX тренера видны в анкете) за **199 ₽/мес**.
Остальные функции (календарь записи, афиша, ответы на отзывы) помечены
«Скоро» — уже показаны в интерфейсе как превью, но не продаются.

**Оплата — через СБП**, не карту. Причина: Алёна самозанятая без ИП,
а для классического карточного эквайринга с расчётным счётом это
недоступно. Из провайдеров СБП-подписок для самозанятых подтверждённо
подходит **ЮKassa** (через приложение «Мой налог», без расчётного счёта).
Точка и Альфа-Банк — по одним источникам подходят, по другим их
классический эквайринг требует расчётный счёт (недоступен самозанятому) —
это НЕ до конца прояснено, нужно уточнять напрямую у банков.
Т-Банк и CloudPayments — точно НЕ работают с самозанятыми в стандартной интеграции.

**Правило отмены подписки** (уже реализовано в `lib/subscriptionCancel.js`):
- Первые 3 дня с последней оплаты — полный возврат, функция отключается сразу
- Позже — без возврата, но оплаченный период донашивается до конца,
  дальше просто не продлевается
- Это решение бизнеса, не требование закона (для цифровых подписок в РФ
  нет обязательного периода охлаждения) — можно менять, если Алёна захочет

**Телефон тренера — два разных поля, не путать:**
- `Coach.phone` — внутренний, обязателен всегда, никогда не публикуется.
  Нужен для связи и чтобы различать тренеров с одинаковыми ФИО
- `Coach.directContactPhone/Telegram/Max` — публикуются только если
  тренер сам включил `bookingMode: "DIRECT_CONTACT"`

**Отслеживание интереса клиентов:**
- Звонки — через колл-трекинг (подменный номер), это будущая доработка,
  требует отдельного платного провайдера, не встроено сейчас
- Клики по Telegram/MAX — считаются напрямую на сайте бесплатно
  (см. `ContactClick` в схеме, эндпоинт `/api/coaches/:id/contact-click`)
- В админке есть сортировка анкет по популярности кликов (`?sortBy=clicks`)

## Юридический статус документов

Черновики оферты, политики конфиденциальности, пользовательского
соглашения и согласия на SMS/Telegram уже прошли один раунд правок по
замечаниям юриста (актуальные версии — не в этом репозитории, а в общем
пакете `protrenerovkids-dlya-razrabotchika.zip`, папка `03-legal-docs/`).
Остаются открытыми: реквизиты оператора (после регистрации самозанятости),
название платёжного провайдера (после выбора), формулировка возврата
в оферте — юрист отметил, что закон может требовать более широкий
пропорциональный возврат, чем правило "3 дня", это стоит перепроверить.

**Товарный знак:** есть неисключённый риск схожести названия с семейством
"Про-" товарных знаков компании-владельца Продокторов (ООО «МЕДРОКЕТ») —
у них зарегистрированы ПРОДОКТОРОВ, ПРОТАБЛЕТКИ, ПРОБОЛЕЗНИ, ПРОЗАПИСЬ,
но всё в медицинском классе МКТУ, не в спортивном. Риск невысокий, но
не проверен формально патентным поверенным — стоит сделать до серьёзных
вложений в бренд.
